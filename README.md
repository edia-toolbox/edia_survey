# EDIA Survey Toolkit

Modular toolkit for generating surveys in Unity.

## Features

- Dynamic survey generation from JSON or ScriptableObjects.
- Multiple component types: Likert, VAS, Matrix, Dropdowns, etc.
- Easy to extend with custom components.
- Support for 2D and VR (Unity UI based).

## Installation

This is a Unity package. You can install it via the Unity Package Manager using the git URL or by adding it to your `manifest.json`.

```json
"dependencies": {
  "com.edia.survey": "https://github.com/EDIA-Project/edia_survey.git?path=/Assets/com.edia.survey"
}
```
